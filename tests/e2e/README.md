# Tayfa uçtan uca testleri

Gerçek Tayfa masaüstü istemcilerini yerel ve atılabilir bir Tayfa sunucusuna (Stoat, erişim, Activities, LiveKit) karşı çalıştırır.

```sh
pnpm build
pnpm e2e:stack up
pnpm e2e
```

Yapı, kapsam, bulunan hatalar, yeni test yazma kuralları ve sorun giderme için [uçtan uca test rehberine](../../docs/E2E_TESTING.md) bak.
